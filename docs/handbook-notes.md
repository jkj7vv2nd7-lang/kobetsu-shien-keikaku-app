## 反映済み
- 目標の具体性チェック（基準・条件：回数・時間・場面・「自分から」等）→ `src/core/guide.py::check_goal_quality`、保存・承認・AIチェックに統合
- 肯定的表現チェック（否定的目標文の警告）→ 同上
- 引継ぎ要約の6観点化（強み・成長の兆し・有効な工夫と条件・直後の予想支援・糊しろ・願いと目標）→ `SUMMARY_FORMAT`、`POST /api/ai/summary`
- 引継ぎ項目：`handover_to / handover_consent / handover_consent_date / start_ease / effective_supports / episode`
- 作成手順の時期目安 → 下表をUI文言・運用ドキュメントに使用

## 作成手順の時期目安（ハンドブックp3-4）
- 3〜4月：相談・引継ぎ（前任者・他機関、保護者の願い聞き取り）
- 4月：実態把握（行動観察・聞き取り、強みと課題、手立て検討）
- 4月：信頼関係・合意形成（家庭訪問・面談で共通理解）
- 4〜5月末：作成（3年後を見通した長期目標、合理的配慮、校内委員会で検討）
- 5月末まで：保護者への説明・合意形成（修正あれば再検討）
- 随時：支援の実施（ズレがあれば柔軟に修正）
- 年度末・学期末：評価と次年度確認（支援会議、次年度へ引継ぎ）
