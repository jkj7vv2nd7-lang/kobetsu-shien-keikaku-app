# LLM選定（無料範囲・2026-09時点・要再確認）

方針：OpenAI互換HTTPでプロバイダ切替。個人情報は匿名化後のみ送信。既定は `mock`（外部送信なし）。

## 推奨（無料・高速・高性能のバランス）
1. **既定：mock（無料・送信なし）**：開発・学内デモ用。定型文生成＋チェックのみ。コスト0、情報流出0。
2. **日本語品質重視：Gemini Flash（Google AI Studio無料枠）**
   - 例：`gemini-2.5-flash`、OpenAI互換 `https://generativelanguage.googleapis.com/v1beta/openai/`
   - 無料枠例：10〜15 RPM、日数十〜千件程度（モデル・時期で変動）。カード不要。
   - 注意：無料枠はデータ利用の対象になり得る。匿名化必須＋学校判断で有償・オプトアウト検討。
3. **速度重視：Groq（Llama/Qwen系）**
   - 例：`llama-3.3-70b-versatile`、`https://api.groq.com/openai/v1`
   - 無料枠例：30 RPM程度、日1K〜14K件（モデルで変動）。電話番号認証あり。OpenAI互換。
   - 日本語はGeminiに劣る場合あり。要約・下書きの高速化に向く。
4. **完全閉域：Ollama（校内・ローカル）**
   - `http://localhost:11434/v1`、外部送信ゼロ。無料・無制限だがPC性能依存。

## 切替方法
- `backend/.env` の `LLM_PROVIDER=mock|gemini|groq|ollama` と各APIキーで切替。
- レート制限・429時は指数バックオフ＋mockへフォールバック表示。
- 送信前チェック（実名残存検査）を通過しないと送信しない。

## データの取扱い方針
- 既定 `mock` は外部送信ゼロ（学習利用なし）
- 外部LLM利用時は匿名化後のみ送信し、学習利用オプトアウト・データ処理契約を推奨
- 送信内容・利用有無は監査ログに記録する

## 有償化の目安
- 全校一斉作成期（3〜4月）の同時利用で無料枠超過が見込まれる場合は、Gemini有償 or 校内Ollama併用を推奨。
- 学習利用オプトアウトが必要な自治体は有償プラン＋データ処理契約を前提とする。
