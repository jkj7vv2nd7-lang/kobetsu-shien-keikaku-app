# 要件整理（v0.1 2026-09-20）

## 対象
- 特別支援学級 / 特別支援学校 / 通級 / 通常学級（個別計画対象児）の教員
- クラウドWebアプリ（複数教員・学校で共有、ログイン管理）
- 文科省参考様式から開始 → 自治体様式へ拡張

## 2つの計画の定義（文科省ベース）
- **個別の教育支援計画**：乳幼児期〜卒業後までの一貫支援。長期視点（おおむね3年）、家庭・医療・福祉・労働等との連携、保護者合意が必須。R3.6参考様式＝プロフィールシート＋支援シート＋作成・活用プロセス。
- **個別の指導計画**：教育課程の具体化。実態把握 → 年間長期目標（1年）→ 学期・月ごとの短期目標 → 具体的指導手立て → 記録・評価（PDCA）。A4で2〜3枚程度に収める運用が多い。

## 機能要件
1. 児童生徒基本情報・実態・願い・支援履歴の構造化入力
2. テンプレート管理（文科省初期搭載＋自治体xlsx/docx取込＋フィールドマッピング＋年度版管理）
3. 差し込み印刷（プレビュー → PDF/Word/Excel出力）
4. AI支援（匿名化後）：文案下書き / 表現チェック / 整合性チェック / 要約・引継ぎ文
5. 厳密チェック：必須項目・文字数・日付整合・保護者確認フラグ・二重チェック承認フロー
6. 監査証跡（誰が・いつ・何を・AI利用有無）

## 非機能要件（セキュリティ）
- 匿名化してAI利用可（氏名・学校名等はLLM送信NG、ローカルで仮名化）
- 認証＋RBAC（管理職/担任/通級担当/閲覧のみ）、学校・学年・学級スコープ分離
- 通信TLS1.2+、保存時暗号化、JPリージョン、日本法準拠
- PII最小化、保存期間・削除ポリシー、保護者確認ログ
- 将来：校内完結LLM / 閉域利用への切替可能性を残す
